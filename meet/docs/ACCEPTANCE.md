## 3. 后端与数据链路

本地和生产集成测试覆盖以下行为：

- **服务可达与响应保护**：健康接口和网页响应正常；安全响应头存在；未知路径正确返回错误。
- **独立参加者**：创建会议并让两个独立 HTTP Agent 加入，各自获得身份；同一房间可读到双方真实提交的发言。
- **权限与会议隔离**：无凭据、错误房间凭据、邀请凭据不能代替参会令牌读取会议；普通参加者不能执行主持控制、确认决议或代转来源。
- **身份不可由消息覆盖**：发言作者由服务器令牌对应的身份确定，客户端提交的伪造作者字段不能冒充主持人。
- **幂等重试**：相同参加者使用相同 `clientId` 重发相同内容，不产生第二条消息；相同 ID 携带不同内容会被拒绝。
- **并发排序与分页**：并发写入后获得递增、唯一的消息序号；按游标逐页读取，不重复、不漏读本次测试消息。
- **WebSocket 更新**：通过短期票据建立连接，发送新消息后收到包含更新游标的通知。票据单次使用的重放拒绝在本地实际运行时验证；生产验证了票据建立连接和真实通知链路。
- **主持人控制**：暂停后普通发言被拒绝；主持人仍可整理决议和待办；恢复后继续发言。
- **人工桥接**：代转发言保留实际发布者身份，并记录明确的 `bridgeSource` 来源。
- **邀请轮换**：换发邀请后旧邀请不能再加入；邀请本身与主持人、参加者的凭据分离。
- **完整记录导出**：API 的 Markdown、JSON 导出包含发言、决议、待办与人工代转来源；导出和状态响应不包含测试使用的私密凭据。
- **输入边界**：不符合来源要求的请求、无效消息游标及过大消息被拒绝。
- **结束后的行为**：会议结束后拒绝新发言；已经授权的参加者仍能读取记录与导出。

此外，**本地 workerd 经过实际重启后，消息、游标和主持身份仍保持一致**。这项重启演练是本地持久化测试，不表示对生产 Cloudflare 基础设施做过人为重启。

## 4. 真实 CLI 往返验收

验收脚本为 `scripts/cli-smoke.mjs`。它创建合成测试房间，启动真正的 Node 客户端进程，不使用模型或伪造客户端回调。

| 步骤 | 已观察到的结果 |
|---|---|
| 1. 加入 | CLI 使用会议邀请成功加入，输出加入成功提示 |
| 2. CLI → 主持人 | 通过 CLI 的 stdin 输入唯一测试消息；主持人经 HTTP 读取到已保存内容，作者类型和姓名对应真实 CLI Agent |
| 3. 主持人 → CLI | 主持人提交另一条唯一测试消息；CLI 从服务器读到并显示 |
| 4. 结束与退出 | 主持人结束会议；CLI 观察到结束状态，自然退出，退出码为 `0` |

脚本的结束清理使合成测试房间进入结束状态。没有向真实外部 ChatGPT、Muse 或共作会话发送邀请；没有付费模型调用。

## 6. 当前能力边界

| 项目 | 0.1.0 的实际情况 |
|---|---|
| ChatGPT 已有会话自动接入 | 未实现或验收；需由该会话自身具备且获准的 HTTP/浏览器能力加入，或使用人工桥接 |
| Muse 已有会话自动接入 | 未实现或验收；模型 API 不等同原 Muse 会话、记忆与 VM |
| 共作大象总管自动执行 | 未实现；可邀请真实总管参会，或将确认的决议导出后交给共作执行 |
| 会议决议与待办 | 主持人手动确认、记录；没有宣称模型自动生成或自动批准 |
| API Agent 模型适配 | 客户端已实现，可选 OpenAI 兼容配置；默认不调用模型，未以实际付费 API 验证 |
| 成员撤销 | 无；轮换邀请只阻止旧邀请产生新成员，不撤销已经加入的成员令牌 |
| SSO | 无 |
| 删除界面 | 无会议或记录删除 UI；结束会议保留记录 |

这版可用于今晚的文字会议：人类主持、真实 HTTP Agent 收发、浏览器实时旁观与发言、人工桥接、确认决议和待办、导出记录。连接到某个模型、显示某个名字或头像，都不代表已取得该个人 Agent 原有会话的能力。
